## Tela de Login Responsiva

Uma interface moderna de login focada em design responsivo, organização de código e experiência do usuário.

## Sobre o Projeto

Este projeto consiste em uma tela de login moderna com layout dividido em duas seções:

- Área de apresentação com mensagem de boas-vindas;
- Formulário de autenticação;
- Opções de login por redes sociais;
- Link para criação de conta.

O objetivo principal foi praticar conceitos de Front-End, como estruturação de páginas, estilização avançada e responsividade.

> **Importante:** Atualmente o projeto possui apenas a interface visual. Nenhuma funcionalidade de autenticação ou cadastro está conectada a um backend.

## Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/Anaelica/user
```

### 2. Entre na pasta do projeto

```bash
cd user
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

### 5. Acesse no navegador

O terminal exibirá um endereço semelhante a:

```bash
http://localhost:5174/
```

Abra esse endereço no navegador para visualizar a aplicação.
